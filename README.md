# fieldtunerecords.com

Official website of Fieldtune Records — nature ambience, environmental recordings, and original music loops.

## Local preview

Open `index.html` in a browser, or:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

## Deploy (GitHub Pages)

1. Push this repository to GitHub.
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`.
3. Custom domain: `www.fieldtunerecords.com` (already set in `CNAME`).
4. Point DNS at GitHub Pages (see `CLAUDE.md`), then enable **Enforce HTTPS**.
